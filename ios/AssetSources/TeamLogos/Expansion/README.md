# Version 1.1 expansion team logo masters

These eight 1024 x 1024 transparent PNGs are the user-approved source masters
for the Pocket Vector expansion identities. They are presentation references
for the normalized Swift emblem primitives and the projected field-paint
layers; runtime UI does not load these large masters directly.

The approved labeled review board is retained at
`QA/expansion-team-logo-approval-board-final.png`.

All marks were created with the built-in ImageGen workflow using the shipping
eight-team midfield review as the style reference. Each was generated on a
flat magenta chroma field, converted to alpha with the installed imagegen
helper, and normalized to a centered square without recoloring.
