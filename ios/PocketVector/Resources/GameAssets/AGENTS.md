# Shipping game-asset ownership

This subtree belongs to the Art Director workstream.

- These files ship in the application. Do not leave drafts, alternates,
  previews, or unused exports here.
- Preserve existing resource paths when practical.
- When physical files change, update `native-assets.json` so the manifest and
  bundle match exactly.
- Art may change manifest inventory entries but not its schema or the runtime
  loading contract without a Technical handoff and PM approval.
- Verify transparent edges, pixel scaling, animation consistency, color
  contrast, file size, and landscape presentation before handoff.
